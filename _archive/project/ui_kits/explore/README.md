# Hostliday Orbit — Explore

The discovery + saved-research surface. Place-led, photo-forward.

## Files
- `index.html` — homepage with hero, search composer, curated rails, and a saved-trip drawer.
- `Hero.jsx` — full-bleed photo hero with wordmark and primary CTA.
- `SearchComposer.jsx` — large-target search with destination, dates, and free-text notes.
- `PlaceRail.jsx` — horizontal rail of place cards.
- `PlaceCard.jsx` — image-led card with pin, title, region, price.
- `SavedDrawer.jsx` — right-side panel showing saved items, drag to reorder.
- `TopBar.jsx` — wordmark + nav + saved counter + avatar.
