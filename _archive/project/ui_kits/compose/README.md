# Hostliday Orbit — Compose

Trip-builder surface. Slot in existing bookings, compare saved candidates, assemble a coordinated itinerary.

## Files
- `index.html` — split-pane: timeline on the left, comparison + Orbit chat on the right.
- `Timeline.jsx` — day-by-day scrollable timeline with slotted items.
- `OrbitChat.jsx` — assistant pane with suggestions and one-tap actions.
- `CompareTray.jsx` — bottom tray to compare saved candidates side-by-side.
- `BookingPill.jsx` — pill for an existing flight/train/stay the user already holds.
