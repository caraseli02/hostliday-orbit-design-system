# Hostliday Orbit — Recover

When plans change. Agent + human escalation, with rebooking options and refund tracking.

## Files
- `index.html` — incident view: what's wrong, what Orbit's already done, options ahead.
- `IncidentHero.jsx` — banner explaining what changed.
- `OptionCard.jsx` — comparable rebooking options.
- `Timeline.jsx` — what Orbit has done so far, time-stamped.
- `EscalateBar.jsx` — bottom action bar to talk to a human.
