# Hostliday Orbit — Navigate

Live-map trip surface. Dark chrome, the map IS the background. Translucent panels float on top.

## Files
- `index.html` — full-bleed map with floating top bar, current-leg sheet, and bottom action bar.
- `MapStage.jsx` — SVG-based map illustration (placeholder for real map provider).
- `LegSheet.jsx` — current leg / next-up panel.
- `LiveDot.jsx` — pulsing user position.
